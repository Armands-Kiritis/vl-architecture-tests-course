# Architecture tests, from zero

A 25-minute interactive course on architecture tests: what they check, how the tools find a broken
rule without running the app, and how to write your first rule in C# (with Java and TypeScript for
comparison). Five short sections, a quiz after each, a hands-on exercise and a cheat sheet.

**Take the course:** https://armands-kiritis.github.io/vl-architecture-tests-course/

Claude wrote it from a single prompt, as the worked example for a Visma Labs article on using
Claude to build your own learning material. The prompt is on the course's start screen.

It is one self-contained `index.html`, built to be embedded in an intranet page through an iframe.
Quiz answers are kept only in the reader's own browser.

The source lives in the Visma Labs requirements repo; this repo is a published copy. Don't edit it
here.
